# 条件設定・候補から個別銘柄を新しいタブで確認

v0.6.57 では、「条件設定・候補」の候補一覧と「統合候補一覧（抽出条件 + 最新トレンド）」の銘柄コード／企業名をクリックした際、個別銘柄検索を新しいブラウザタブで開きます。

## 目的

- 元の候補一覧、抽出条件、ソート状態を維持したまま個別銘柄を確認する。
- 確認後は新しいタブを閉じるだけで候補一覧へ戻れるようにする。
- v0.6.56 の「履歴・実績検証」と同じURLクエリ方式を共通利用する。

## 安全境界

この変更はUIナビゲーションだけを対象とします。抽出条件、Yahoo Finance/J-Quantsデータ取得、外的要因レビュー、SBI証券連携の安全境界は変更しません。
