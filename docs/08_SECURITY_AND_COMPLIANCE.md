# Security and Compliance

## 秘密情報

許可する環境変数:

- `JQUANTS_API_KEY`
- `EDINET_API_KEY`

禁止する保存情報:

- SBI証券ユーザー名
- SBI証券ログインパスワード
- SBI証券取引パスワード
- ワンタイムパスワード
- セッションCookie
- ブラウザー保存認証情報

`.env` はGit管理しない。ログへAPIキーを出力しない。

## SBI証券との境界

- 公式に確認できるAPI案内は先物・オプション向け。
- 国内現物株の注文APIは本システムの前提にしない。
- SBI証券のWeb画面やアプリの自動操作を実装しない。
- 発注は人間が公式画面で行う。

## データ利用規約

- 各データサービスの個人利用条件、再配布条件、保存期間を確認する。
- APIレスポンスを第三者へ再配布しない。
- 文書やデータを公開成果物へ含める場合は利用条件を再確認する。

## 監査ログ

各実行で次を保存する。

- 実行日時
- コードバージョン
- 設定ファイルハッシュ
- データソースと取得日時
- 入力ファイルハッシュ
- 候補と除外理由
- 人間レビュー
- 注文案と承認履歴

## 障害時

- データ取得失敗時に前回データで注文案を生成しない。
- 一部銘柄だけ欠落した場合は処理を成功扱いにしない。
- 価格データの時点が不明な場合は `order-ready` にしない。
- 異常時は安全側に停止する。
