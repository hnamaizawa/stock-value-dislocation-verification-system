# v0.6.63 戦略検証

## 目的

「外的要因で株価が低迷しているが、本業は壊れておらず、反転後に回復する銘柄を選ぶ」という仮説を、今後の実績待ちだけに依存せず検証するための機能です。

## 1. Point-in-time Walk-Forward

ローカルのcuratedデータだけを使い、過去の各評価日時点までに存在した株価と、当時までに開示済みの財務情報だけで定量条件を再計算します。その後、v0.6.61の反転確認条件を適用し、10/20/30/60/90/180日後の実績を確認します。

未来情報混入を避けるため、現在のニュースや現在の人手レビューを過去日に遡って適用しません。この検証が再現するのは「定量条件 + 構造悪化ガード + 反転確認」です。完全な過去◎☆の再現ではありません。

52週高値からの下落率を正しく再現するため、標準では評価日前に252営業日以上ある日だけを対象にします。ローカル株価履歴が短い場合、評価可能な過去日は少なくなります。

## 2. 類似非選択銘柄とのMatched Control比較

Walk-Forwardで選ばれた銘柄ごとに、その日に選ばれなかった銘柄から対照群を作ります。同業種を最優先し、同業が不足する場合は同一市場へ広げます。

距離計算には、取得できる範囲で以下を使います。

- 時価総額
- 52週高値からの下落率
- 6か月騰落率
- 同業PER比
- 同業PBR比
- 自己資本比率

候補リターンから類似非選択銘柄の平均リターンを引いた値を「選択超過」として表示します。これにより、単に市場全体が上昇しただけなのか、システムの選択自体に追加価値があったのかを確認できます。

## 3. External Shock Attribution（外因説明率）

6か月騰落率を次の3要素へ記述的に分解します。

- 市場成分: 正式TOPIXを優先し、なければ明示されたTOPIX ETF代理値
- 業種成分: 同業種中央値 - 市場成分
- 企業固有成分: 個別銘柄 - 同業種中央値

外因説明率は、個別銘柄が6か月で下落している場合に、その下落の何%が同業種中央値の下落でも説明できるかを0〜100で表します。同業比較は5銘柄以上ある場合だけ有効です。

これは因果関係の証明ではありません。高スコアは「市場・業種側の下落と整合的」、低スコアは「企業固有の弱さが大きい」ことを示す補助指標です。v0.6.63では新しいhard filterにはせず、前向き実績とWalk-Forward結果を見てから閾値化を判断します。

## 性能と安全性

- 画面を開いただけではWalk-Forwardを実行しません。
- 実行は「戦略検証」画面の明示ボタンのみです。
- J-Quants / Yahooへの追加アクセスは行わず、既存curatedデータだけで計算します。
- SBIログイン、ブラウザ自動化、自動注文は行いません。
