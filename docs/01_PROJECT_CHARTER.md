# Project Charter

## 目的

ユーザーが希望する「業績は悪くないが、一時的な外的要因で株価が低迷している企業を安く買う」という調査方針を、再現可能なデータ処理とリスク管理へ落とし込む。

最終成果は、実際の株価・財務・開示・保有状況を使って、次を含む**注文直前パケット**を生成することである。

- 候補銘柄と除外理由
- 株価下落の主因
- 一時要因・構造要因の切り分け
- 直近3年の売上、営業利益、営業CF
- 財務体力と同業比較
- 回復カタリスト
- 失敗シナリオと仮説無効化条件
- 最新決算・開示資料の根拠
- 保有株、買付余力、集中度を反映した注文案
- 指値、数量、最大投資額、参考撤退条件
- 人間による承認記録

## 対象

- 日本国内上場株式
- 原則として現物買い
- 中期の価格正常化を狙う調査支援
- 日次または週次の候補抽出
- 決算・適時開示時の再評価

## 非対象

- 高頻度取引、デイトレード
- 信用取引、空売り、先物・オプション
- SBI証券への自動発注
- SBI証券Web画面の自動操作
- LLMだけで完結する投資判断
- SNS投稿だけを根拠にしたイベント判定

## 成功条件

1. 同じ `as_of` と同じ元データから同じ候補を再生成できる。
2. 各指標の元データと開示時点を追跡できる。
3. 注文案が保有状況・現金・リスク上限を超えない。
4. 外的要因、投資仮説、失敗条件に人間の承認がある。
5. システム単独ではSBI証券へ注文できない。
