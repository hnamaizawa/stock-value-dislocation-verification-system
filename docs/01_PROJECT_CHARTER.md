# Project Charter

## 目的

営業実態・財務が大きく崩れていない一方で外的要因により株価が低迷している可能性のある日本株を見つけ、株価が回復を始める兆候を日々確認できるようにする。過去チャート、株価、自己資本比率、売上、経常利益率などの企業情報、開示情報、配当情報をpoint-in-timeで整理し、候補抽出から予測の事後検証までを一貫して支援する。

アプリは投資判断を代行しない。候補ごとに根拠、データの基準日、注意点、反証条件を示し、実際に投資するかは利用者が決める。利益を保証する予測器ではなく、仮説を再現可能に検証する調査支援ツールとする。

中心成果は、実際の株価・財務・開示・配当情報を使って、次を含む調査・検証結果を生成することである。

- 候補銘柄と除外理由
- 株価下落の主因
- 一時要因・構造要因の切り分け
- 直近3年の売上、営業利益、営業CF
- 財務体力と同業比較
- 回復カタリスト
- 失敗シナリオと仮説無効化条件
- 最新決算・開示資料の根拠
- 日次のトレンドと反転状況、継続リスク
- 配当利回り、配当額、配当性向、増減配見込みと持続性の注意
- 選定時点から10、20、30、60、90、120、240、365取引日後の価格推移による事後検証
- デイトレード向けの流動性・ボラティリティ・日中値幅の独立した分析
- 根拠、失敗シナリオ、仮説無効化条件

注文案やポートフォリオ連携は後続の任意機能であり、中心目的ではない。提供する場合も人間の確認を必須とする。

## 対象

- 日本国内上場株式
- 原則として現物買い
- 中長期の価格回復候補を探す調査支援
- 日次または週次の候補抽出
- 決算・適時開示時の再評価
- デイトレード向け銘柄の値動き・流動性の補助分析（中長期候補と別戦略・別評価）

## 非対象

- 高頻度取引、自動デイトレード、自動発注
- 信用取引、空売り、先物・オプション
- SBI証券への自動発注
- SBI証券Web画面の自動操作
- LLMだけで完結する投資判断
- SNS投稿だけを根拠にしたイベント判定

## 成功条件

1. 同じ `as_of` と同じ元データから同じ候補・指標を再生成できる。
2. 各指標の出典、データ基準日、開示時点を追跡でき、将来情報を選定に混ぜない。
3. 選定ルールの将来成績を指定した8つの取引日 horizon で評価し、未確定件数とサンプル数を併記する。
4. 中長期の企業・配当評価とデイトレードの値動き評価を分けて提示する。
5. 外的要因の認定は一次資料を人が確認し、アプリは確実な上昇や無条件の買いを表示しない。
6. システム単独では証券会社へ注文できない。
