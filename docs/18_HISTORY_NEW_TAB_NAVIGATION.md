# 履歴一覧から個別銘柄を新しいタブで開く

v0.6.56 では、「履歴・実績検証」の日次分析履歴・評価履歴・◎☆銘柄サマリ・◎☆イベント詳細から個別銘柄を確認するとき、元の履歴画面を置き換えず、新しいブラウザタブで「個別銘柄検索」を開きます。

- 履歴一覧の銘柄コードまたは企業名は `st.link_button` で開きます。
- 新しいタブは別の Streamlit セッションになるため、URL クエリ `code` に銘柄コードを渡します。
- 個別銘柄検索は初回表示時に `code` を読み取り、検索欄と選択銘柄を自動設定します。
- 元の履歴タブの検索条件、ページ番号、ソート状態には触れません。
- 条件設定・候補画面からの既存の `st.switch_page` による同一タブ遷移は維持します。

J-Quants / Yahoo Finance 系のデータ取得、定量抽出ルール、自動ルール学習、外的要因レビュー、SBI 証券に関する安全境界は変更しません。
