# Data Directory

## ディレクトリ方針

```text
data/
  sample/       # 架空データ。デモ専用
  raw/          # APIレスポンス等の加工前スナップショット
  staged/       # プロバイダー別に正規化した中間データ
  curated/      # 検証済みの内部データ契約
  reviews/      # 人間レビューと承認
  portfolio/    # SBIから手動取得したCSV等。秘密情報は禁止
```

## 重要

- `sample` と実データを同じ実行で使わない。
- Rawは原則上書きせず、取得日時ごとに保存する。
- 実データをZIP配布物へ含めない。
- SBI証券の認証情報を保存しない。
- 保有CSVは個人情報を含み得るため、Git管理しない。
